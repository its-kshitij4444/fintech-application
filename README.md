# FinTradeSim

FinTradeSim is a full-stack stock market simulation platform that enables users to explore the stock market through live price tracking, interactive charts, AI-powered assistance, and paper trading. It combines a Java Servlet/JSP web application with a Python-based stock agent to deliver a realistic trading experience without using real money.

The project was built to demonstrate full-stack development, database management, real-time market data integration, authentication, and AI-assisted stock analysis in a single application.

---

## Features

### Market Experience
- Search and autocomplete for NSE stock symbols
- Live stock quotes with optional auto-refresh
- Interactive candlestick and volume charts
- Detailed stock information pages

### Paper Trading
- Buy and sell stocks using virtual funds

- Holdings overview
- Profit and loss tracking

### AI Stock Assistant

### Dashboard

## Getting Started

### Prerequisites

- JDK 21
- Apache Tomcat 9
- MySQL
- Python 3.x
- Flask

### Installation

1. Clone the repository.

```bash
git clone https://github.com/its-kshitij4444/fintech-application.git
```

2. Configure the MySQL database.

3. Update database credentials in the application configuration.

4. Install Python dependencies.

```bash
pip install -r requirements.txt
```

5. Start the Python stock agent.

6. Deploy the Java application on Apache Tomcat.

7. Open the application in your browser.
